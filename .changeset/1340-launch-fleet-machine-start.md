launch-fleet starts a spec's fleet on to-tickets' machine plan approval, with no human approval, and reads the owner's comments on the spec's video: stop holds the fleet, reset asks for a re-cut and a new video, and anything else is a steer it reads. Video comments steer only when the OpenWiz App posted the video; while agents post from the owner's login, they steer nothing and the check says so once.
