`fleet.sh` reads each issue's detail, native blockers and comments by GraphQL, twenty issues to a query with comments paged back to the first, and passes every remaining REST read through the read budget (`budget.py`): a refused or unknown allowance, a missing comment page or a failing `gh` now stops the check with exit 2, and eight lanes replace the 64-lane REST pool.
