# Measuring kit (retired)

The measuring kit was removed in openwizdev/OpenWiz#1868 because nothing runs it. Its full form is in git history at `5921369`.

The files left here stay only because historical records under `skills/*/evidence/` link to them or quote their command:

- `static-count.cjs` counts a paths manifest's tokens: `node tools/measure/static-count.cjs <paths.json> <tokenizer>`.
- `baseline-paths.json` is the WS1 baseline manifest.
- `evidence/` holds the WS1 baseline rows, the static baseline and the LV1 receipts.

They go when those records go.
